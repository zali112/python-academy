# Python Academy

Интерактивная образовательная платформа по Python: **уроки с запуском кода прямо в браузере**, задачи с автопроверкой, проекты, тренажёры, справочники Python и компьютерных сетей, прогресс и достижения.

Статическое приложение без сервера и обязательной регистрации: открывается с GitHub Pages, локально и офлайн.

---

## Стек

| Слой | Технологии |
| --- | --- |
| Интерфейс | React 18, TypeScript (strict), React Router 6 |
| Стили | Tailwind CSS, собственный UI-кит в стиле shadcn/ui, Lucide Icons |

| Сборка и деплой | Vite, GitHub Actions → GitHub Pages |

## Быстрый старт

```bash
npm install        # установка зависимостей
npm run dev        # локальный dev-сервер: http://localhost:5173
```

> Нужен Node.js 18+. На Windows PowerShell `npm.ps1` может блокироваться политикой выполнения — используйте `npm.cmd` или Git Bash.

### Основные команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер с HMR |
| `npm run build` | типизация + production-сборка в `dist/` |
| `npm run preview` | локальный просмотр собранного сайта |

## Архитектура исполнения кода

Контент и UI не знают, *как* исполняется Python. Всё сводится к интерфейсу `PythonRunner`
(`src/runner/types.ts`):

```ts
interface PythonRunner {
  readonly id: "demo" | "pyodide" | "server";
  run(code: string, options?: RunOptions): Promise<RunResult>;
}
```

- **demo** — собственный интерпретатор учебного подмножества Python на TypeScript:
  работает мгновенно, офлайн, без доступа к файлам и сети.
- **pyodide** — настоящий CPython в WebAssembly, грузится с CDN при первом запуске.
- **server** — зарезервированный идентификатор: позднее сюда подключается sandbox-бэкенд,
  не меняя страниц и компонентов.

Переключение — в **Настройках**.

## Прогресс и данные

- Весь прогресс (уроки, задачи, тесты, избранное, заметки, активность, серия) хранится в
  `localStorage` браузера: ни сервера, ни аккаунтов, ни сетевых запросов с данными.
- **Экспорт/импорт JSON** — на странице «Настройки» и «Мой прогресс»: файл переносит прогресс
  между браузерами и устройствами.
- **Сброс** выполняется только после подтверждения.

## Контент

Весь текст — на русском языке, без заглушек:

- 13 курсов в каталоге: 6 опубликованы с уроками, остальные показывают полную программу;
- 35 уроков структурированы по единому шаблону (цель, теория, пример, разбор построчно,
  редактор, ошибки, задание, тест, памятка);
- 20+ задач с открытыми и скрытыми тестами;
- 5+ проектов с этапами, критериями и эталонным решением;
- тренажёры на 8 типов вопросов;
- справочник Python (встроенные функции, методы типов, исключения, stdlib) и справочник сетей
  (DNS, TCP, HTTP, TLS, OSI) — с примерами только на `127.0.0.1`/`localhost`.

Контент лежит в `src/data` и описан типами из `src/types/content.ts` — его можно заменить на
API, не трогая страницы.

## Публикация на GitHub Pages

1. Создай репозиторий и запуши код:

   ```bash
   git init
   git add .
   git commit -m "Python Academy"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

3. Workflow `.github/workflows/deploy.yml` при пуше в `main` сам:
   - установит Node и зависимости,
   - прогонит типизацию, линт и unit-тесты,
   - соберёт сайт с `VITE_BASE=/<repo>/` (корректный base path для Pages),
   - скопирует `dist/index.html` в `dist/404.html` (SPA-фолбэк для неизвестных маршрутов),
   - задеплоит на Pages.

4. Сайт появится по адресу `https://<username>.github.io/<repo>/`.

### Локальная проверка сборки под Pages

```bash
VITE_BASE=/python-academy/ npm run build   # Windows (PowerShell): $env:VITE_BASE="/python-academy/"; npm run build
npm run preview
```

## Проверка качества

```bash
npm run typecheck && npm run lint && npm test && npm run build
```

- **Unit-тесты (Vitest)** — интерпретатор Python, прогресс и XP/серия, поиск и подсветка,
  целостность контента (id, ссылки, обязательные поля, безопасность сетевых примеров).
- **E2E (Playwright)** — навигация, запуск кода в уроке, 404, поиск, настройки, доступность,
  проверка отсутствия внешних хостов в сетевом справочнике.

## Безопасность

- код пользователя исполняется **только в браузере** (демо-интерпретатор или Pyodide-песочница);
- сервера нет — значит, нет и утечки данных: прогресс не покидает устройство;
- сетевые примеры обращаются исключительно к `127.0.0.1` и `localhost`;
- секретов, ключей и сторонних аналитик в проекте нет;
- доступные с клавиатуры компоненты, skip-link, `aria-*`-атрибуты, адаптивная вёрстка.
